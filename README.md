#  Pokémon-Style 2D RPG

##  What is this project?
This is a custom-built 2D Pokémon-style role-playing game developed from scratch using vanilla JavaScript and HTML5 Canvas. Explore the overworld map, talk to quirky villagers, step into tall grass to trigger random monster encounters, and battle enemies using a turn-based combat system!

##  How I built it
* **HTML5 Canvas & CSS:** Used for rendering the game world, custom UI elements, dialogue boxes, and responsive health bars.
* **JavaScript:** Powers the core game loop, player movement, tile-based collision detection, NPC interactions, and turn-based battle mechanics.
* **GSAP (GreenSock):** Handles smooth screen transitions, battle fade-ins/fade-outs, and UI animations.
* **Howler.js:** Manages background music and sound effects for the overworld and combat scenes.

##  How to Play
* **[Play the game online here!][(https://abuxisp.github.io/Pokemon-game/)]** 
* **Movement:** Use the **W, A, S, D** keys to walk around the map.
* **Interact:** Press the **Spacebar** when standing near an NPC to talk and read dialogue.
* **Combat:** When a random battle triggers in the tall grass, click on your monster's attack buttons in the battle menu to execute moves and defeat the enemy!

##  How to Run Locally
1. Clone or download this repository.
2. Open the project folder in **VS Code**.
3. Use the **Live Server** extension in VS Code to run `index.html` locally in your browser.
